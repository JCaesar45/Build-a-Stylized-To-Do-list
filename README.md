# Stylized To-Do List

A simple, interactive to-do list built with HTML and CSS. This project demonstrates the use of link styling in different states: default, hover, focus, active (clicked), and visited. It also includes basic list structure and semantic accessibility best practices.

## 🚀 Features

- Custom styles for checkbox tasks and link states
- Accessible structure with proper `label` and `for` attributes
- External links that open in a new tab
- Clean, minimal UI design

## 🧱 Technologies

- HTML5
- CSS3

## 📁 Project Structure

```

stylized-todo-list/
├── index.html        # Main HTML file
├── style.css         # Custom styles
└── README.md         # Project documentation

````

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/stylized-todo-list.git
````

2. Open the project folder:

   ```bash
   cd stylized-todo-list
   ```

3. Open `index.html` in your browser.

## 🧩 Usage

Each to-do item includes:

* A checkbox to mark the task
* A label with a description
* A sub-item list linking to external resources

### Link States

| State   | Style         |
| ------- | ------------- |
| Default | Blue text     |
| Hover   | Orange text   |
| Active  | Red text      |
| Focus   | Green outline |
| Visited | Purple text   |

## 🛠️ Customization

* Edit `style.css` to change colors, fonts, or spacing.
* Add more list items by copying the `<li>` structure inside the `.todo-list` `<ul>`.

## 🎯 Learning Objectives

* Practice HTML structure for to-do lists
* Learn and apply different CSS pseudo-classes:

  * `:hover`
  * `:active`
  * `:focus`
  * `:visited`
